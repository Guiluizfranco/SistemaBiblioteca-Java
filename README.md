# Sistema de Biblioteca em Java

Sistema de gerenciamento de biblioteca desenvolvido em Java via console, com funcionalidades de cadastro, listagem, busca e remoção de livros e usuários.

## Objetivo do projeto 
Este projeto foi desenvolvido com fins de estudo para praticar:

Lógica de programação
Programação Orientada a Objetos
Estruturação de projetos Java
Manipulação de listas
Tratamento de erros e exceções

## Funcionalidades

### Livros
- Cadastrar livros
- Listar livros
- Buscar livros por código
- Remover livros

### Usuários
- Cadastrar usuários
- Listar usuários
- Buscar usuários
- Remover usuários

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- Collections (`ArrayList`)
- Tratamento de exceções (`try-catch`)
- Scanner para entrada de dados

## Estrutura do projeto

src/
|__ model
|__ service
|__ repository
|__ biblioteca (main)

## Como executar

1. Clone o repositório
2. Abra em uma IDE Java
3. Execute a classe Main.java
